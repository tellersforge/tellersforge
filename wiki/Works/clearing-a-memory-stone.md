# Clearing a Memory Stone


*aka: ______________________________*

Wiping a stored memory from its token so that it can be used again. The one who clears it first reads what the stone holds, which means living through it, then erases the memory, and finally renews the runes that were worn by the old one. It is quiet work, and uncomfortable when the memory was painful. Some clearers keep a journal of what they have erased; many refuse to.

## Phases

*Wipe a stored memory from an object. Size: Minor.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| Read what it holds | [Memory Reading](../Powers/memory-reading.md) | 1 | T |
| Erase the memory | [Memory Erasure](../Powers/memory-erasure.md) | 1 | B |
| Renew the runes | [Rune & Sigil Magic](../Powers/rune-and-sigil-magic.md) | 1 | T |

## Not to be confused with

*[Copying a Memory Stone](copying-a-memory-stone.md)*, which duplicates what a stone holds; Clearing a Memory Stone erases it.
