# Memory Stone


*aka: ______________________________*

A small token, often a flat stone, that holds a memory as clear as the day it happened. The token is shaped, runes and wards are engraved to keep what it will hold, the maker recalls the memory with perfect clarity, and then imprints it. Anyone who holds the stone and knows the way can live the memory as if it were their own. Families keep them, spies trade them, and grief makes them precious.

## Phases

*Implant a memory into an object. Size: Minor.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| Shape the token | [Stone Toolmaking](../Skills/stone-toolmaking.md) | 1 | T |
| Engrave the runes and wards | [Rune & Sigil Magic](../Powers/rune-and-sigil-magic.md) | 1 | T |
| Recall it clearly | [Memory Training](../Skills/memory-training.md) | 1 | B |
| Imprint the memory | [Memory Imprinting](../Powers/memory-imprinting.md) | 1 | B |

## Not to be confused with

*[Sealed Memory Stone](sealed-memory-stone.md)*, which only the key-holder can read; an ordinary Memory Stone opens to anyone who knows how.
