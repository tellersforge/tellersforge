# Copying a Memory Stone


*aka: ______________________________*

Copying a stored memory onto a second stone. The copier reads the original, living through it fully, then imprints what they experienced onto a fresh token. The copy is faithful but not perfect: it carries a faint trace of the copier's own feelings. Collectors prize originals for that reason, and forgers exploit it. Libraries of memory are built, slowly, this way.

## Phases

*Copy a stored memory onto a second stone. Size: Minor.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| Read the original | [Memory Reading](../Powers/memory-reading.md) | 1 | T |
| Imprint the copy | [Memory Imprinting](../Powers/memory-imprinting.md) | 1 | B |

## Not to be confused with

*[Clearing a Memory Stone](clearing-a-memory-stone.md)*, which erases a stone for reuse; Copying a Memory Stone reproduces what it holds.
