# Seer's Dispatch


*aka: ______________________________*

A memory stone made in a living messenger. The seer looks across the miles at a distant place, then imprints what he saw into a trained bird, which is sent home. There, another reads the memory from the bird, and sees what the seer saw. It is faster than any rider, and a bird is harder to stop than a courier. The birds are treated like royalty, and they know it.

## Phases

*A memory stone made in a living messenger instead of a stone: the seer implants what he saw with Far Seeing into a bird, which carries it home. Size: Minor.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| See the distant place | [Far Seeing (Clairvoyance)](../Powers/far-seeing-clairvoyance.md) | 1 | B |
| Implant the memory in the bird | [Memory Imprinting](../Powers/memory-imprinting.md) | 1 | B |
| Send the bird home | [Falconry](../Skills/falconry.md) | 1 | T |
| Read the memory from the bird | [Memory Reading](../Powers/memory-reading.md) | 1 | T |

## Not to be confused with

*[Memory Stone](memory-stone.md)*, which holds a memory in a stone; a Seer's Dispatch carries it in a living bird.
