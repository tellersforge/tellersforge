# Permanent Clerical Blessing


*aka: ______________________________*

A god's blessing fixed into an object for good. The object is prepared, consecrated with full rite, and then the priest seeks the Spirit's leave, because this is not a thing to presume. The blessing is invoked, and at last sealed with divine authority so that it never fades. Altars, bells, shields and relics made this way are treasured by temples, and fiercely guarded.

## Phases

*Imbue an object with a god's blessing or clerical spell for good. Size: Great.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| Prepare the object | (the craft skill that makes it) | 2 | T |
| Consecrate it | [Ritual & Liturgy](../Skills/ritual-and-liturgy.md) | 3 | T |
| Seek the Spirit's leave | [Commune](../Powers/commune.md) | 1 | B |
| Invoke the blessing | [Blessing](../Powers/blessing.md) | 3 | B |
| Seal it with the Spirit's authority | [Permanency](../Powers/permanency.md) | 3 | B |

## Not to be confused with

*[Blessed Charm](blessed-charm.md)*, a small, humbler blessing; a Permanent Clerical Blessing fixes a god's favour into an object forever.
