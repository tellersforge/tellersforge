# Sealed Memory Stone


*aka: ______________________________*

A memory stone that only the key-holder can read. The token is shaped, runes and wards engraved, a key devised, whether a word, a pattern or a small object, then the memory is imprinted and the whole is sealed. To anyone else it is a pretty pebble. Royal messages, secret confessions and dangerous knowledge travel this way, hidden in plain sight.

## Phases

*Implant a memory that only the key-holder can read. Size: Minor.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| Shape the token | [Stone Toolmaking](../Skills/stone-toolmaking.md) | 1 | T |
| Engrave the runes and wards | [Rune & Sigil Magic](../Powers/rune-and-sigil-magic.md) | 1 | T |
| Devise the key | [Cryptography](../Skills/cryptography.md) | 1 | T |
| Imprint the memory | [Memory Imprinting](../Powers/memory-imprinting.md) | 1 | B |
| Seal it | [Memory Sealing](../Powers/memory-sealing.md) | 1 | B |

## Not to be confused with

*[Memory Stone](memory-stone.md)*, which opens to anyone who knows how; a Sealed Memory Stone opens only to the key.
