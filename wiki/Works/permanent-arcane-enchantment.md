# Permanent Arcane Enchantment


*aka: ______________________________*

A spell fixed into an object for good. The object is made or prepared by its craft, runes are inscribed on it, the spell is cast into them, and at last it is made permanent, so that it never fades. A lamp that never goes out, a lock that cannot be picked, a blade that never dulls. Such objects are rare because the last step costs so much, and the maker must be sure of every step before it.

## Phases

*Imbue an object with a spell that never fades. Size: Great.* T = transferable (anyone with the skill can do it); B = bound (must be done by the owner or the one with the power).

| Phase | Skill or power | Passes needed | T/B |
|---|---|---|---|
| Make or prepare the object | (the craft skill that makes it) | 3 | T |
| Inscribe the runes | [Rune & Sigil Magic](../Powers/rune-and-sigil-magic.md) | 3 | T |
| Cast the spell into it | (the power being stored) | 3 | B |
| Make it permanent | [Permanency](../Powers/permanency.md) | 3 | B |

## Not to be confused with

*[Enchanted Item](enchanted-item.md)*, which carries a crafted, attuned magic; a Permanent Arcane Enchantment fixes one particular spell into an object forever.
