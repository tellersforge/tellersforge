# 14. Table Settings

*Set: Core*

Decide these together at the first meeting and tick them on the Table Settings page. They belong to the whole table, not to any one character. ★ marks our recommendation. Basic's five choices come first, unchanged; Core adds the rest.

| Setting                     | Choices                                                                                                                                   |
|-----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| The setting                 | Where and when the story happens; which weapons, armour, shields and powers exist. ★ A fantasy world with swords, bows, shields and magic |
| Rest                        | A night's sleep gives back 1 Life (gritty) · 1d6 ★ · all Life (heroic)                                                                    |
| 0 Life                      | The Game Master decides ★ · the dying roll                                                                                                |
| XP pace                     | Slow (about 5 a session) · Standard (about 10) ★ · Fast (about 20)                                                                        |
| Luck                        | Use the Luck rolls ★ · leave Luck out                                                                                                     |
| Check style                 | Core: one die per attribute ★ · Basic: one die, −4 for extra attributes                                                                   |
| Flaws                       | Standard nine ★ · swap any for chosen flaws · chosen flaws only                                                                           |
| Critical hit                | Damage dice twice, armour applies ★ · skip armour · double all damage · something wild                                                    |
| Fumble                      | One mishap ★ · confirmation roll first · no penalty · comic mishap                                                                        |
| Critical success on a check | Best result plus a small extra ★ · a lasting advantage · an XP award                                                                      |
| Critical failure on a check | Fail plus a setback ★ · plain failure · comic twist                                                                                       |
| Power cost                  | Magic Energy Pool ★ · fatigue · uses per day                                                                                              |
| Level Up points             | Spread over different skills ★ · any way the player likes                                                                                 |
| Shields                     | Parry bonus, blocks missiles ★ · absorbs one hit, then splinters                                                                          |
| Armour-piercing rounds      | Armour counts half · fixed reduction · special rounds ignore armour                                                                       |
| Deeper steps in use         | armour by body part · armour wear · gear durability · stray rounds · limb damage · size in a fight · fatigue                              |
| Permanent injuries          | On · off                                                                                                                                  |
| Species in this world       | A short list · a genre to start from · anything the Game Master agrees · high-power species allowed or not                                |
| Rewards                     | Well-played flaws 1–5 XP ★ · extras for clever play and roleplay ★                                                                        |
