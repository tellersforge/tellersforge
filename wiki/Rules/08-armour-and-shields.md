# 8. Armour and Shields

*Set: Core*

### Armour, unchanged

Armour has one number. When you are hit, take your Armour total off the damage; what is left comes off Life. If the armour takes it all, the hit does nothing. Armour is not damaged or used up: it takes the same amount off every hit. Robes and ordinary clothes are not armour: Armour 0, Dodge penalty 0. Layers of real armour add together.

| Armour                           | Value | Dodge penalty |
|----------------------------------|-------|---------------|
| None: robes, plain clothing      | 0     | 0             |
| Light (leather, padded)          | 1     | 0             |
| Medium (mail)                    | 2     | −2            |
| Heavy (plate, ceramic plates)    | 4     | −4            |
| Technical (personal force field) | 3     | 0             |

Those are Basic's five classes. Gear / Core lists armour piece by piece, by era, each with its value, penalty, weight and price; the classes above are the same numbers seen from a distance.

### Core adds: armour by body part

The sheet's body outline has a value box for each part: head, torso, arms, legs. Write each piece's value on the parts it covers; the best layer counts, and a second real layer adds +1, never more. Your **Armour total** is the average of head and torso, the two that matter most, rounded down. Most tables just use the total. When someone aims at a particular spot (chapter 6), use that spot's number.

A soldier with a plate carrier and no helmet has a low total. That is honest: his head is exposed.

Rifle rounds go through all old-style armour; the numbers already make that happen.

### Core adds: armour wear (deeper step)

By default, armour just works and never wears out. Tables that want more give each piece a second number: how many real hits it can take. Hits that do not beat the armour cause no wear. Steel takes a fair amount almost for ever; ceramic plates stop nearly anything, but only a handful of times.

### Core adds: armour-piercing rounds

A table setting. Choose one: armour counts half; armour is reduced by a fixed amount; or special rounds ignore armour completely.

### Shields

Basic's shield rule stands: any character may carry one if the setting has them; a shield is not armour; it adds 2 to Parry, so Parry is Melee Attack − 1; it blocks arrows and some magic; it takes one hand, so it cannot be used with a staff or a heavy two-handed weapon. Core refines the bonus by the shield:

| Shield                          | Parry bonus | Against missiles                                                         |
|---------------------------------|-------------|--------------------------------------------------------------------------|
| Buckler                         | +1          | parries thrown weapons only                                              |
| Round shield (Basic's "shield") | +2          | parries arrows, bolts, stones, thrown weapons                            |
| Kite shield                     | +3          | as round, and partial cover (−2 to be hit) while raised                  |
| Tower shield                    | +4          | as kite, and heavy cover (−4) while braced; you cannot attack that round |
| Riot or ballistic shield        | +2          | the only shields that stop bullets; built for it                         |

- A shield parries once per round, like a weapon, each against a different attack. The Shields skill is for bashing with it.
- **Magic:** a shield blocks a damaging power only in part: the damage is halved, rounded down, then armour comes off. Lightning goes through shields and armour alike.
- Ordinary shields do not stop bullets or blaster fire; only shields built for it do.
- A shield adds nothing to your armour value.
- Some groups prefer: a shield absorbs one hit completely, then splinters. Mark it on the Table Settings page.
