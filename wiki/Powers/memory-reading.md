# Memory Reading

*Set: Expansion*

*aka: ______________________________*

A raven lands on the shoulder, and the bearer sees what the raven saw. A crystal, a scroll or a messenger animal holds a memory, left there on purpose, and the bearer reads it. At first it is only a blurred scene; at its best, every detail exactly as it was seen: faces, words, light, weather.

It is how some sorcerers and spymasters send their messages, and how they get them back. It needs something that has been deliberately given a memory; ordinary objects do not carry one.

## Game block

- **Dice:** 2 · **Attributes:** **WIS**/INT · **Mastered at:** +5 | 2
- **What it does:** read a memory that has been stored in an object or a messenger animal
- **Minor → major:** a blurred scene → every detail, exactly as seen
- **Cost:** 3 Energy (version I)
- **What failure looks like:** Only a blurred, uncertain scene. Spectacular failure: the bearer reads the memory wrongly, or loses their own.

## Not to be confused with

*[Object Reading](object-reading.md)*, which senses any object's past by touch; memory reading only reads memories deliberately stored.

## Costumes

- **Arcane:** a hand on the familiar's head, and its memories unfold in the mind.
- **Technology:** a data crystal or recorder played back through an implant.

- **Close to:** [Object Reading](object-reading.md), [Memory Imprinting](memory-imprinting.md)
