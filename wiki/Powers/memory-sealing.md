# Memory Sealing

*Set: Expansion*

*aka: ______________________________*

A lock on a remembered moment. The user takes an object holding an imprinted memory and closes it, so that only the right person, the right word or the right token can open it. To anyone else, the stone is silent, or shows only a grey fog.

Diplomats seal their messages this way, generals their battle orders, lovers their promises. At its mildest, a determined reader can break the lock with effort. At its greatest, the seal is unbreakable, and if the key is lost, the memory is lost with it. Many old stones in many vaults hold secrets no one alive can read.

## Game block

- **Dice:** 3 · **Attributes:** **INT**/INT/WIS · **Mastered at:** +5 | 3
- **What it does:** lock a stored memory so only someone with the key can read it
- **Minor → major:** a simple lock → a seal no one else can break
- **Cost:** 4 Energy (version I)
- **What failure looks like:** The lock doesn't hold; the memory stays open to all. Spectacular failure: it locks for everyone, including the rightful reader.

## Not to be confused with

*[Cryptography](../Skills/cryptography.md)*, the skill, which hides meaning in written codes; Memory Sealing locks a stored memory itself.

## Costumes

- **Arcane:** a sigil pressed into the stone and a key word spoken, known only to the intended reader.
- **Tech (encryption):** a cipher key woven into the stored data, readable only with the matching code.
