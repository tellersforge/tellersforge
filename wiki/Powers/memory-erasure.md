# Memory Erasure

*Set: Expansion*

*aka: ______________________________*

Wiping an object's memory clean. The user takes a stone, bone or bird that carries an imprinted memory and draws the image out of it, leaving nothing behind. The object can then hold something new, or simply be destroyed without fear of what it might tell.

It is the quiet trade of spies, forgers and record-keepers who need to reuse their materials. At its mildest, the memory is blurred into uncertainty. At its strongest, it is gone completely, and no amount of skill can recover it. Courts often suspect it when evidence goes missing, and not without reason.

## Game block

- **Dice:** 2 · **Attributes:** **INT**/WIS · **Mastered at:** +5 | 2
- **What it does:** wipe a stored memory from an object so it can be reused or can't be read
- **Minor → major:** blur it → wipe it clean
- **Cost:** 3 Energy (version I)
- **What failure looks like:** The memory stays intact, or only partly fades. Spectacular failure: the erasure slips, and the user loses a memory of their own.

## Not to be confused with

*[Memory Imprinting](memory-imprinting.md)*, which puts a memory into an object; Memory Erasure takes it out.

## Costumes

- **Arcane:** a palm passed over the stone, drawing the image out like steam from a cup.
- **Technology:** a wiping program that overwrites stored data until nothing remains.
