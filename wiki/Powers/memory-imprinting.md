# Memory Imprinting

*Set: Expansion*

*aka: ______________________________*

Pressing a memory into a thing, like a seal into wax. The user holds a prepared stone, a piece of bone, a slab of carved wood, or cups a messenger bird in both hands, and recalls something seen. The memory settles into it. Later, anyone with the means can read it back: the sight, the sound, sometimes the smell of the moment.

It is the record-keeper's gift. Witnesses imprint what they saw for the courts, scouts send back a picture of the enemy camp, grieving families keep a last clear image of someone lost. At its greatest, a full account survives in a form no advocate can argue with. It cannot hold what has not happened; prophecies and dreams slide off it like water.

## Game block

- **Dice:** 2 · **Attributes:** **INT**/WIS · **Mastered at:** +5 | 2
- **What it does:** fix a memory of something seen into a prepared object (stone, bone, wood) or a living messenger such as a bird, so others can read it later; foretellings won't hold
- **Minor → major:** one clear moment → a full, court-worthy account
- **Cost:** 3 Energy (version I)
- **What failure looks like:** The memory won't settle, or comes out blurred. Spectacular failure: the wrong memory goes in, possibly something private the user never meant to share.

## Not to be confused with

*[Memory Reading](memory-reading.md)*, which reads a person's memories; Memory Imprinting fixes one into an object. *[Store Power](store-power.md)* bottles a working instead.

## Costumes

- **Arcane:** a smooth stone held to the brow while the user recalls, glowing briefly as the image settles.
- **Technology:** a recording implant that saves what the eyes saw to a crystal chip.
