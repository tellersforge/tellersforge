# Security Systems

*Set: Expansion*

*aka: ______________________________*

Alarm bells, pressure plates, cameras on the corners and doors that open only for the right card. Security Systems is knowing how these things are laid out, wired and watched, and therefore how to put them in, or how to get past them without anyone noticing.

The installer and the burglar share the same knowledge and only differ in which side of the door they stand. One walks a building thinking about blind spots, cable runs and response times; the other walks it thinking exactly the same thing. Banks, museums and rich families employ the first sort, and sometimes find that yesterday's installer is tonight's thief. In older ages the skill covers bells on strings and tripwires; in newer ones, motion sensors, heat cameras and locks that remember faces.

## Game block

- **Dice:** 3 · **Attributes:** **INT**/DEX/PER · **Mastered at:** +5 | 3
- **Needs:** electricity · **Covers:** alarms, cameras, electronic locks: installing and bypassing
- **Why these attributes:** knowledge, handwork, spotting the flaw
- **What failure looks like:** the system isn't understood, or the installation has gaps. Spectacular failure: the alarm is tripped, the camera catches a face, or the new system locks in its own owner.

## Not to be confused with

*[Lockpicking](lockpicking.md)*, which opens mechanical locks by hand; and *[Hacking](hacking.md)*, which breaks into computers. Security Systems deals with the whole alarm and sensor network.
