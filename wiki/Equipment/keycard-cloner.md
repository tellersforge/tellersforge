# Keycard cloner

*Set: Expansion*

*aka: ______________________________*

*Security and thievery · Needs: computing · modern*

A small reader, easily hidden in a sleeve or a folder, that picks up the code from a keycard in a passing pocket or on a lanyard. A few seconds close to the target is enough. Back in a quiet corner, the code is written onto a blank card, and the thief walks through the door with the confidence of an employee. The only skill needed is standing near the right person.
