# Sonar set

*Set: Expansion*

*aka: ______________________________*

*Optics, sensing and scanners · Needs: electricity · modern*

A console, a speaker and a transducer bolted beneath a ship's hull. It sends a sharp ping down into the water and times the echo back, so the operator can see the depth, the rocks, the sunken wreck and the long shape of a submarine. Watching a sonar screen is patient, sleepy work until the moment it isn't. The trouble is that every ping carries a long way, and anyone listening knows exactly where it came from.

## Game block

- **Bonus:** +2 Searching underwater; +1 Sea Navigation finding depth and hazards
- **Penalty:** −1 Stealth its pings can be heard
- **Used for:** [Communications & Sensors](../Skills/communications-and-sensors.md)
- **Weight:** 60 kg · **Needs:** electricity · **Price:** 40 S
- **Also known as:** echo sounder

## Not to be confused with

the *[Hydrophone](hydrophone.md)*, which only listens and gives nothing away; the sonar set speaks, and finds more for it.
