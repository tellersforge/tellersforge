# Teller's Forge

An open tabletop game system for stories of every era, built by the Collaboration Team and its community.

This repository holds the public wiki pages (the game system itself): rules, species, skills, powers, gear and creatures. Suggestions and improvements go through the Collaboration Team, who read, test and decide on each one. The top priority is simple gameplay; simple character creation comes second.

Site: https://tellersforge.netlify.app
